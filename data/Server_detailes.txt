6️⃣ NGINX SETUP (REVERSE PROXY)

Create site config

sudo nano /etc/nginx/sites-available/sivadurga.in

HTTP → HTTPS redirect

server {
    listen 80;
    server_name sivadurga.in www.sivadurga.in;
    return 301 https://$host$request_uri;
}

HTTPS + Reverse Proxy

server {
    listen 443 ssl http2;
    server_name sivadurga.in www.sivadurga.in;

    ssl_certificate /etc/letsencrypt/live/sivadurga.in/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/sivadurga.in/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enable site

sudo ln -s /etc/nginx/sites-available/sivadurga.in /etc/nginx/sites-enabled/

Test & reload

sudo nginx -t
sudo systemctl reload nginx
